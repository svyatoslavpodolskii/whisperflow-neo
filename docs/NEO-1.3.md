# WhisperFlow: Neo 1.3

Версия 1.3-neo / versionCode 5. Оба APK берутся из артефакта WhisperFlow-Neo.
Это оптимизированные release-варианты с прежним сохранённым ключом CI. GitHub Releases не публикуются.

## Запись

На Galaxy Watch 6 40 mm пользователь сообщил о пропусках и повторах звука, особенно после
холодного запуска. Изменения потоков AudioRecord в 1.2 проблему не устранили. Улучшение при
повторном запуске указывает на влияние стартовой нагрузки, но не доказывает её точную причину.

В 1.3 системный MediaRecorder захватывает микрофон и пишет AAC ADTS mono / 48 kHz / 96 kbit/s.
Приложение больше не читает PCM и не записывает каждый блок через JVM во время записи.
После Stop MediaCodec декодирует аудио, потоковый resampler переводит его в PCM16 mono 16 kHz.
Доставка использует прежний WAV и durable ACK. AAC — сжатие с потерями.
ADTS остаётся в spool до сохранения WAV; старые PCM journals также восстанавливаются.
Если оборванный источник не декодируется, он сохраняется для последующей диагностики.

При быстром запуске сразу показывается подготовка, без вспышки кнопки микрофона.
Состояние записи включается после фактического MediaRecorder.start. Одна анимация появления
за 220 ms; дальше только индикатор текущего peak раз в 80 ms в draw phase. Нет истории
с задержкой, постоянной пульсации и декоративной волны. Нажатие индикатора останавливает запись.
UI не сканирует outbox во время подготовки и записи.

## Интерфейс и файлы

- Настройки сразу занимают окончательные позиции, без stagger transitions. Промежутки между секциями одинаковы.
- Список заметок показывает заголовки и дату, действия находятся в меню.
- Строка хранилища показывает «Память приложения» либо выбранную общую папку. Приватная память
  недоступна Obsidian; для общей работы нужно выбрать свою папку через системный picker.
- Обычная заметка открывается с форматированием, новая — сразу в редакторе.
  YAML и техническая ссылка на WAV скрыты, но сохраняются в Markdown-файле.
- Отсутствие файла в выдаче DocumentsProvider больше не удаляет локальную заметку.
  Локальная версия экспортируется повторно. Удаление из Neo — явное действие пользователя.

## Общая корзина

Удаление заметки убирает из обычных списков и её аудио. До истечения срока они восстанавливаются
вместе. Срок — 30 дней по умолчанию, переключается на 7 дней в корзине.
WorkManager проверяет срок ежедневно; также очистка выполняется при синхронизации/открытии.
Точный момент фонового запуска определяется Android.

По истечении срока удаляются приватные Markdown, аудио и черновик. Tombstones в SQLite остаются,
чтобы повторная доставка/чтение истории не воскрешали удалённое.
Из общей папки Markdown и attachment убираются при синхронизации удаления;
восстановление экспортирует их снова из локальной корзины.

## Проверки и ограничения

Локально 28 октября 2026 успешно собраны оба assembleRelease APK. Проверки testDebugUnitTest:
телефон — 39 тестов, часы — 13, без ошибок. Подписи пары совпадают; APK часов не debuggable.
PNG списка заметок и индикатора визуально проверены.

Проверяются длительность и значения при 48→16 и 44.1→16 kHz, границы codec buffers,
сохранность metadata при редактировании, пропажа внешнего файла без удаления локального,
восстановление аудио и окончательная очистка после срока. Реальные Compose-компоненты
списка заметок и индикатора отрисовываются в PNG. Пиксельная проверка подтверждает реакцию
индикатора на текущий уровень и отсутствие действия «Запись» во время подготовки.

Robolectric не записывает физический микрофон и не подтверждает качество native AAC на
Galaxy Watch. Для этого нужна проверка APK после холодного запуска.

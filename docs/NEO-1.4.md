# WhisperFlow: Neo 1.4

Версия 1.4-neo / versionCode 6 устанавливается поверх 1.3. Ключ подписи не менялся;
CI проверяет закреплённый SHA-256 обоих APK. Новая установка или перенос данных не нужны.

## Заметки и редактор

- Верхний ряд: папка хранилища, синхронизация, корзина, новая заметка. Плашка памяти,
  дублирующее меню хранилища и отдельный переход к аудио убраны. Аудио находится в заметке.
- Нижняя навигация использует микрофон, документ и настройки вместо прежних неверных значков.
- Заметка сразу открывается в визуальном редакторе с заголовками, жирным/курсивом,
  списками, ссылками, зачёркиванием и inline-кодом. Есть undo/redo и переключение в исходный Markdown.
- Обычный Markdown остаётся содержимым файла; YAML и техническая ссылка на аудио не попадают
  в редактируемое тело. Сохраняются чек-листы и ссылки Obsidian. Полная замена текста через
  accessibility SetText обрабатывается отдельно от посимвольного редактирования.
- Таблицы, fenced code, цитаты, HTML/сложные вставки открываются в исходном Markdown:
  текущая версия визуальной библиотеки не должна молча удалять неподдерживаемую структуру.
- Удержание заметки включает выделение. Нажатие переключает выбранный элемент, доступны
  «Выбрать все», массовое удаление и отмена выделения кнопкой Back.
- В корзине доступны массовое восстановление, удаление навсегда и полная очистка с подтверждением.
  Вместе с заметкой удаляется аудио. Срок 7/30 дней теперь выбирается в настройках приложения.

За ориентир взята эргономика Notely Voice: редактирование прямо в документе, компактная панель
форматирования и значки действий. Исходники Notely Voice под GPL-3.0 не копировались.
Используется Apache-2.0 Compose Rich Editor 1.0.0-rc10, совместимый с Kotlin 2.0.21 / Compose 1.7.
Android-исходники включены в модуль rich-editor. Исправлена обработка замен текста от клавиатуры:
замена нескольких абзацев и исправления равной длины больше не определяются по разнице длин.
Проверка использует настоящий путь ввода IME, а не только accessibility SetText.
Атрибуция — в THIRD_PARTY_NOTICES.md. Основная Apache-2.0 лицензия проекта сохранена.

## Настройки

- Выбор live-расшифровки хранится независимо от доступности режима. Gateway временно
  отключает live, не перезаписывая выбор; возврат в Local его восстанавливает.
  Ручное переключение сразу обновляет экран и сохранённые настройки.
- Язык речи, задача, адрес сервера и параметры обработки сохраняются при изменении,
  без обязательного нажатия Save. Отмена скачивания модели не изменяет язык.
- В карточке языка показывается рекомендация модели с учётом языка и памяти.
  Она не выбирает и не скачивает другую модель без действия пользователя.
- Задача «Перевод» означает перевод Whisper на английский, не создание задачи планировщика.
  Она применяется к основному local/GPU распознаванию и обработке записей часов.
  Gateway в текущем клиенте поддерживает только transcribe.
- «Обработка диктовки» использует внешний LLM Gateway. В LOCAL эта опция недоступна,
  включая фоновые потребители настройки. Локальная нейросеть Whisper уже встроена в приложение;
  отдельная LLM для переформулирования текста не встроена.
- Шаблон скопированного текста локализован; прежний английский стандартный шаблон мигрирует,
  пользовательский сохраняется. Всплывающее окно ассистента действительно использует этот шаблон.
- У основного экрана записи есть собственные варианты визуализации: столбики, волна, кольцо.
  Они не зависят от настроек Snake/Tree/Card у окна цифрового ассистента.

## Что означают дополнительные функции

Локальный сервер распознавания — HTTP API на самом телефоне для других клиентов сети.
Это не сервер синхронизации часов. Проверка: GET /status, отправка multipart-аудио: POST /transcribe,
порт по умолчанию 8060.

Системный ассистент — вход в диктовку по удержанию питания. Требуются выбор Neo цифровым
ассистентом Android и, на Samsung, отдельное назначение боковой кнопки. Для аппаратного PTT
нужна служба специальных возможностей, для плавающих окон — разрешение отображения поверх приложений.
PTT записывает, пока выбранная кнопка громкости удерживается. Голосовая клавиатура использует
двойное нажатие уменьшения громкости. Прошивка может перехватывать питание раньше приложения.

Внешние Tasks, Streak и Assistant — интеграции исходного PiMax, не встроенные локальные сервисы:

| Сервис | Порт на выбранном хосте | Контракт |
|---|---:|---|
| Tasks | 8058 | GET /api/health; POST /api/tasks с title и source=whisper |
| Streak / привычки | 8055 | GET /api/health; POST /api/whisper-hook с text, source, timestamp |
| Внешний ассистент | 8073 | GET /api/health; POST /api/whisper-hook |
| Авторизация PiMax | 8100 | GET /api/whoami |
| LLM Gateway | 8068 | Отдельный сервер распознавания/обработки Gateway |

Во вкладке подключений можно задать полный URL хоста, не меняя режим распознавания Local.
Сервисы должны быть развёрнуты отдельно и доступны через Wi-Fi/VPN. Без них переключатели
оставляют выключенными. Пустой адрес больше не вызывает запрос относительного /api/whoami
и не показывается как ошибка распознавания речи. HTTPS сохраняется при вычислении адресов.
Фоновые клиенты получают те же адреса, что и основной экран.

## Статусы и уведомления

Список заметок показывает очередь, текущую расшифровку и ошибку с повтором; аудио доступно
в самой заметке. Если итоговый текст приходит в открытый, ещё не изменённый документ, он обновляется.

В «Поведение приложения» независимые настройки:

- статус расшифровки: тихое foreground-уведомление на время работы, исчезает после завершения;
- уведомления новых непросмотренных заметок: тихие, с переходом прямо к заметке;
- просмотр заметки снимает её уведомление и отметку непросмотренного;
- разрешение POST_NOTIFICATIONS запрашивается один раз, после разрешения микрофона;
  при отказе доступен переход в системные настройки уведомлений.

При выключенном статусе worker не запрашивает foreground-режим: длительная фоновая обработка
подчиняется ограничениям WorkManager/Android. Аудио уже находится в durable inbox и не удаляется.
При прерывании расшифровка возвращается в состояние очереди.

## Проверки

Проверяются визуальный Markdown round-trip, чек-листы/ссылки, замена документа и последний символ,
многовыбор, корзина/окончательное удаление, тихие уведомления и их снятие, миграция SQLite 3→4,
адреса сервисов, рекомендации моделей и сохранение настроек.
Два теста настоящей записи DataStore 1.0 запускаются на Linux CI: Java File.renameTo не может
атомарно заменить существующий файл на Windows, в отличие от Android/Linux.
PNG списка и редактора создаются настоящими Compose-компонентами в Robolectric.
Проверки на конкретных прошивках кнопки питания, специальных возможностей и системных разрешений
потребуют устройства; автоматические тесты не подтверждают OEM-перехват аппаратных кнопок.
